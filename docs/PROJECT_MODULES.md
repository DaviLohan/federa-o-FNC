# Project Modules

## users
Autenticacao, user model, player profile, team owner profile, verificacao de email, reset de senha.

## fnc_teams
Times, memberships, convites, limite de elenco, formacoes, leave requests.

## fnc_championships
Campeonatos, inscricoes, standings, grupos, bracket, agenda e fases.

## fnc_matches
Partidas, reports, gols, assistencias, cartoes, contestacoes, confirmacoes, lineups, WO.

## player_stats
Estatisticas individuais/coletivas, rankings, season summaries, weekly selection.

## fnc_notifications
Notificacoes in-app e email.

## fnc_payments
Pagamentos de inscricao, Mercado Pago, Asaas legado, webhooks.

## ea_integration
Clubes EA, aliases, EAMatches, stats de jogadores EA, relay, report matching.
