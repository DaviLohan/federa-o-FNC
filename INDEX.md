## 💡 Dicas de Navegação

### No Terminal
```bash
# Ver índice rápido
cat INDEX.md | grep "###"

# Buscar em todos os docs
grep -r "keyword" *.md

# Ver status
cat PROJECT_SUMMARY.md | grep "✅"
```

### No Editor
- Use `Ctrl+F` para buscar
- Todos os arquivos têm índice no topo
- Links funcionam no GitHub/VSCode

### Online
- Todos os arquivos funcionam no GitHub
- Markdown renderizado automaticamente
- Links entre arquivos funcionam
